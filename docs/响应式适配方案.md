## 二、设计原则

### 1. 移动优先（Mobile First）
所有样式默认针对手机写，再用 `sm:` / `md:` / `lg:` 逐步增强。Tailwind 的断点是"最小宽度"生效，所以：
```jsx
// 正确：默认手机样式，md: 增强桌面
<div className="flex flex-col md:flex-row gap-2">
// 错误：默认桌面样式，再用 max-md 降级（Tailwind 没有 max-md）
```

### 2. 统一断点口径
| 断点 | 宽度 | 用途 |
|------|------|------|
| 默认 | <640px | 手机竖屏（基准） |
| `sm:` | ≥640px | 手机横屏 / 小平板 |
| `md:` | ≥768px | 平板 / 小笔记本（导航切顶部 tabs） |
| `lg:` | ≥1024px | 桌面（多栏布局） |

**关键规则**：`md:` 是"手机↔桌面"的分界线。手机用底部 tab bar + 单栏，桌面用顶部 tabs + 多栏。

### 3. 容器策略
- **主内容容器**统一用 `max-w-4xl mx-auto px-4 md:px-6`（最大 896px，居中，手机 16px 内边距，桌面 24px）
- **全屏聊天/学习页**用 `h-[calc(100vh-80px)]`（减去导航高度），手机底部 tab bar 占 56px
- **卡片网格**用 `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4`（手机 1 列，平板 2 列，桌面 3 列）

### 4. 触控区与字号
- 按钮最小触控区 **44×44px**（`min-h-[44px] min-w-[44px]`）
- 正文 `text-sm`（14px），标题 `text-base`（16px），手机不小于 12px
- 间距用 `gap-2`（8px）起步，手机 `p-3`、桌面 `md:p-6`

## 三、各页面改造方案

### ⚠️ AiChatView（中优先 · 重点）

**现状**：2 处断点，宽屏（桌面）整个聊天区被挤在中间窄条里，左右大量留白浪费。

**改造**：桌面端用**侧栏 + 主聊天区**双栏布局，手机端保持单栏下拉式（已改）。

```jsx
// 外层容器：手机单栏，md 以上双栏
<div className="flex flex-col md:flex-row h-[calc(100vh-80px)] gap-3 px-3 md:px-6 py-4">
  {/* 左侧栏：场景/换词/模型（桌面显示，手机隐藏收进顶部） */}
  <aside className="hidden md:flex md:w-72 shrink-0 flex-col gap-3">
    {/* focus word 卡片 */}
    {/* 场景下拉 */}
    {/* 模型信息 */}
  </aside>

  {/* 主聊天区 */}
  <main className="flex-1 flex flex-col min-w-0">
    {/* 手机端顶部紧凑 header（md:hidden） */}
    <div className="md:hidden ...">换词下拉 + 场景下拉 + 译文开关</div>
    {/* 聊天消息 */}
    <div className="flex-1 overflow-y-auto ...">...</div>
    {/* 输入框 */}
    <div className="...">...</div>
  </main>
</div>
```

**效果**：桌面端左侧 288px 侧栏放场景/单词/模型，右侧主聊天区占满剩余空间；手机端侧栏隐藏，控件收到顶部紧凑 header（已实现）。

### ⚠️ StudyView（中优先）

**现状**：7 处断点，卡片宽度 `max-w-2xl`，手机端答题按钮区偏小。

**改造**：
1. 卡片容器：`max-w-2xl mx-auto w-full px-4 md:px-6`（手机全宽，桌面居中 672px）
2. FSRS 评级按钮（Again/Hard/Good/Easy）：手机端 `grid grid-cols-2 gap-2`（2×2），桌面 `md:flex md:gap-3`（横排）
3. 卡片内容字号：手机 `text-base`，桌面 `md:text-lg`
4. 翻转卡片触控区：整卡可点击，`min-h-[280px] md:min-h-[340px]`

```jsx
{/* FSRS 评级按钮 */}
<div className="grid grid-cols-2 gap-2 md:flex md:gap-3 mt-4">
  <button className="min-h-[44px] ...">Again</button>
  <button className="min-h-[44px] ...">Hard</button>
  <button className="min-h-[44px] ...">Good</button>
  <button className="min-h-[44px] ...">Easy</button>
</div>
```

### ⚠️ StatsView（中优先）

**现状**：4 处断点，FSRS 分布图 + 各种统计卡片在手机端挤压。

**改造**：
1. 统计卡片网格：`grid grid-cols-2 md:grid-cols-4 gap-3`（手机 2 列，桌面 4 列）
2. FSRS 分布条形图：宽度 `w-full`，高度固定，手机端标签用 `text-[10px]`
3. 学习曲线图：`h-40 md:h-56`（手机 160px，桌面 224px）
4. 日历热力图：手机端 `grid-cols-7` 保持，但格子 `w-6 h-6 md:w-8 md:h-8`

## 五、通用改造清单（全局）

1. **统一主容器**：所有页面外层用 `<div className="max-w-4xl mx-auto px-4 md:px-6 py-4 md:py-6">`
2. **统一卡片样式**：`rounded-2xl md:rounded-3xl border border-slate-200 dark:border-slate-800 bg-white dark:bg-slate-900 p-4 md:p-6 shadow-xs`
3. **统一间距**：`gap-2 md:gap-3`、`space-y-3 md:space-y-4`
4. **统一字号**：标题 `text-base md:text-lg`，正文 `text-sm`，辅助 `text-xs`
5. **统一触控区**：所有按钮 `min-h-[44px]`，图标按钮 `p-2 md:p-2.5`
