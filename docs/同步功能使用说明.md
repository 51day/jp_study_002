# 背单词 · PostgreSQL 云端同步 · 使用说明

> 版本：2026-10-30 · 适用项目：memorize-word（背单词 FSRS + AI）

本文档面向**使用者**，介绍新增的「Vercel + Neon PostgreSQL 离线优先自动同步」功能如何使用、如何配置，以及与原有 WebDAV 备份的关系。

---

## 一、功能概览

本次升级为背单词应用接入了一套**跨设备实时同步**能力：

- **离线优先**：本地数据始终可用，断网也能正常背单词；联网后自动后台同步。
- **自动同步**：背单词、改设置、加自定义词等操作会自动累计，达到阈值或静置 20 秒后推送云端，无需手动操作。
- **跨设备无缝衔接**：在 A 设备背的词、解锁的成就、加的自定义场景，会在 B 设备登录后自动合并出现。
- **不丢数据**：按时间戳智能合并，新旧设备数据都能保留；删除操作也能跨设备生效。
- **保留 WebDAV**：原有 WebDAV 网盘备份完全保留，作为独立的冷备份手段。

## 二、启动与登录

### 本地启动
```bash
bun install        # 安装依赖（项目使用 bun）
bun run dev        # 启动开发服务器（tsx server.ts）
```
浏览器访问 http://localhost:3000 。

### 登录
启动后需输入**全局访问密码**登录。密码在项目根目录 `.env` 文件的 `ACCESS_PASSWORD` 中配置：
```env
ACCESS_PASSWORD="你的密码"
```
> 本地试用时，WorkBuddy 已生成一个 `.env`，默认密码为 `memorize2026`，可自行修改。

## 三、云同步状态指示器（顶栏）

应用顶栏右侧新增了一个**云同步状态小徽标**，实时反映同步状态：

| 状态 | 显示 | 颜色 | 含义 |
|------|------|------|------|
| `synced` | 已同步 | 绿色 | 本地数据已成功推送到云端 |
| `syncing` | 同步中... | 蓝色（转圈） | 正在与云端交换数据 |
| `offline` | 离线缓存 | 灰色 | 云端不可达，本地正常使用，数据不丢 |
| `error` | 同步失败 | 红色 | 同步出错，可点击重试 |

**点击徽标** = 立即手动触发一次同步推送。鼠标悬停可看到上次同步时间或错误详情。

## 四、设置页 · PostgreSQL 同步卡片

进入「设置」页，在 WebDAV 区块**上方**新增了一张「**PostgreSQL 云端实时同步**」卡片，包含：

- **当前同步状态**与**上次同步时间**
- **「立即同步」按钮**：手动把本地数据推送到云端
- **「从云端重新拉取合并」按钮**：从云端拉取最新数据并与本地合并（用于换设备后主动刷新）

下方的 **WebDAV 卡片**保持原样，作为独立网盘冷备份，两者职责清晰区分：
- **PostgreSQL**：日常自动实时同步（高频、低延迟）
- **WebDAV**：手动/定时全量冷备份（坚果云、Nextcloud、群晖 NAS 等）

## 五、启用真正的云同步（配置 Neon 数据库）

默认情况下（未配置数据库），同步状态显示「离线缓存」，本地功能完全正常。要启用跨设备云同步，需配置一个 PostgreSQL 连接串（推荐 [Neon](https://neon.tech) 免费版）。

### 步骤
1. 在 Neon（或 Supabase / Vercel Postgres / 自建 PG）创建一个数据库，拿到连接串，形如：
   ```
   postgresql://user:password@ep-host.region.aws.neon.tech/neondb?sslmode=require
   ```
2. 写入项目根目录 `.env`：
   ```env
   DATABASE_URL="postgresql://user:password@ep-host.region.aws.neon.tech/neondb?sslmode=require"
   ```
   （部署到 Vercel 时，则在 Vercel 项目的 Environment Variables 里设置 `DATABASE_URL`）
3. 重启服务器（`bun run dev`）。
4. 登录后，应用会**自动**：
   - 后台创建同步表（`app_universal_sync`，首次自动建表）
   - 首次登录静默从云端拉取并合并
   - 后续每次背词/改设置自动推送

> Neon 免费版会休眠，连接超时已从 5 秒调大到 **15 秒**，容忍冷启动唤醒。

## 六、离线模式行为

- 未配 `DATABASE_URL`、或网络中断、或数据库休眠唤醒失败时，同步状态自动转为「**离线缓存**」。
- **离线时本地学习、AI 对话、WebDAV 备份均不受影响**。
- 同步失败不会清空或污染本地数据；恢复网络后下一次操作会自动重试推送。

---

## 七、重置数据的注意事项

「设置 → 重置所有数据」的确认弹窗中已明确说明：

> ⚠️ 此操作**仅清空当前浏览器的本地缓存**，不会删除 PostgreSQL 云端与 WebDAV 备份。下次登录仍可从云端恢复。

即：重置后换设备/重新登录，云端数据依然可拉回。

## 八、常见问题

**Q1：换了新手机登录，为什么会先弹「定制学习起点」引导窗？**
A：已修复。新设备登录后会**先从云端拉取数据**，若云端显示已完成引导，则不再弹窗；只有云端也未完成引导时才会弹。

**Q2：为什么内置的 13 个预设 AI 场景不会占用我的数据库额度？**
A：同步时**只上传用户自建的场景**（`isCustom === true`），内置预设场景不上云，避免大段 Prompt 反复传输。其他设备会自动补齐内置预设。

**Q3：我在 A 设备删除了一个自建场景，B 设备会同步删除吗？**
A：会。删除时会写入「墓碑」记录并同步，B 设备拉取后会自动移除该场景。

**Q4：WebDAV 密码、AI API Key 会被同步到 PostgreSQL 吗？**
A：不会。同步范围仅限：学习进度、自定义词、自建场景、学习日志、成就、用户设置。WebDAV 配置、密码、Token、API Key 等敏感信息**绝不入库**。

**Q5：同步会频繁打数据库吗？**
A：不会。采用防抖 + 批次权重机制：累计变更达到 10 个（如背满 10 个词）或静置 20 秒才推一次；切到后台时立即推、切回前台超 2 分钟才静默拉。保护 Neon 免费额度。

## 九、数据同步范围一览

| 数据类型 | 是否同步 | 合并策略 |
|----------|---------|---------|
| 学习进度（FSRS 状态/复习时间/收藏/笔记） | ✅ | 按 `updatedAt` 取较新，时间相同按 `reps` 决胜 |
| 学习日志 | ✅ | 按 ID 去重，保留最新 3000 条 |
| 自定义单词 | ✅ | 按 ID 合并，支持软删除 |
| 自建 AI 场景 | ✅ | 仅 `isCustom` 场景，按 ID 合并 + 墓碑删除 |
| 成就 | ✅ | 已解锁优先（保留最早解锁时间），进度取 max |
| 用户设置 | ✅ | 按 `updatedAt` 取较新；引导完成状态任一端为真则保留 |
| WebDAV 配置/密码 | ❌ | 不入库（敏感） |
| AI API Key/Token | ❌ | 不入库（敏感） |
